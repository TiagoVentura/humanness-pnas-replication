# truthsocial\_posts/ README

This folder contains scripts and datasets for converting, filtering, and cleaning Truth Social post data for downstream analysis.

---

## Folder Contents

```
truthsocial_posts/
├── csv_updated/                    # CSV outputs from script 01
├── json_updated/                   # Raw JSON/NDJSON post data
├── 01_convert_to_csv.py             # Converts JSON files in json_updated/ into CSVs in csv_updated/
├── 02_cleaning.py                   # Filters and cleans debate-day and evening posts
├── day_of_debate_posts.csv          # All posts from 2024-09-10 (generated by 02_cleaning.py)
├── requirements.txt                 # Python dependencies
└── README.md                        # This file
```

---

## Prerequisites

* **Python 3.7+**
* Install dependencies via:

  ```bash
  pip install -r requirements.txt
  ```

---

## Scripts Overview

### 1. `01_convert_to_csv.py`

**Purpose:**

* Reads all `.json`/NDJSON files in `json_updated/`.
* Normalizes nested lists/dicts into flat CSV-friendly rows.
* Saves converted CSVs into `csv_updated/`.

**Usage:**

```bash
python 01_convert_to_csv.py
```

---

### 2. `02_cleaning.py`

**Purpose:**

* Reads all CSV files in `csv_updated/` and:

  * Generates `day_of_debate_posts.csv` (all posts from **2024-09-10**).
  * Creates HTML-cleaned `_readable.csv` files for selected debate-day CSVs in `csv_files_cleaned_updated/`.
  * Produces `evening_debate_posts_clean.csv` (posts between **7:00 PM–11:59 PM ET** on debate day containing `debate2024` or `debatenight`, with usernames masked and URLs replaced with TinyURLs).

**Usage:**

```bash
python 02_cleaning.py
```

---

## Data Files

* **`json_updated/`**: Raw JSON from Truth Social.
* **`csv_updated/`**: Outputs from `01_convert_to_csv.py`.
* **`day_of_debate_posts.csv`**: All posts from the debate day.
* **`csv_files_cleaned_updated/`**: HTML-cleaned readable CSVs for selected debate-day files.
* **`evening_debate_posts_clean.csv`**: Filtered and cleaned evening debate posts.
